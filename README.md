# cyber-security-101
Cyber Security 101 — practical security kits and guides (store)

## Site

Site: static storefront, Stripe Payment Links in config.js, served from main root via GitHub Pages.

Each kit can also be bought on Gumroad. Paste the product URL for that kit into `GUMROAD_LINKS` in `config.js`. An empty value hides the Gumroad button. Stripe checkout stays on the card.
